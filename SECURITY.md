# Security Policy

## Supported Versions

Security fixes are provided for the latest release of Spectre Pro.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report them privately to [security@skyones.co](mailto:security@skyones.co) with:

- A description of the issue and its potential impact.
- Steps to reproduce the issue or a proof of concept.
- The Spectre Pro version and macOS version affected.

We will acknowledge reports within 7 days and work with you on a responsible disclosure timeline.
